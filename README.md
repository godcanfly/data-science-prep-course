# 3-Day Python + Data Science + AI Prep Course

Complete teaching package for a student preparing to enter a US university Data Science program.

## Course Goal

After 3 days, the student will:
- Write Python confidently for data tasks
- Clean and explore a dataset using Pandas
- Create meaningful visualizations
- Build and evaluate a simple machine learning model
- Have one portfolio project on GitHub
- Know exactly what to study next

## Teaching Environment

- **Platform**: Google Colab (recommended) or Jupyter Notebook
- **Python version**: 3.10+
- **Required packages**: `pandas`, `numpy`, `matplotlib`, `seaborn`, `scikit-learn`
- **No local installation needed** if using Google Colab

## Before Day 1

Student should:
1. Create a Google account
2. Create a GitHub account
3. Bring a laptop with internet access
4. Be ready to type code — not just watch

## How to Use This Package

1. Read `0-course-syllabus.md` first
2. For each day, open the corresponding materials file and slides outline
3. Use the `code/` scripts as live coding examples
4. Give students `exercises/` during breaks and afternoon sessions
5. Assign one capstone project from `projects/` on Day 3
6. Share `cheatsheets/` and `student-handout.md` at the end

## Suggested Schedule

Each day runs 9:00 AM – 5:00 PM with two breaks.

| Day | Theme | Morning | Afternoon |
|-----|-------|---------|-----------|
| 1 | Python + Data Wrangling | Python essentials | Pandas basics |
| 2 | EDA + Visualization | Exploratory analysis | Charts + stats |
| 3 | ML + Capstone | First ML model | Complete mini-project |

## Core Principle

> **80% hands-on coding, 20% explanation.** Every student should leave with code they wrote themselves.
