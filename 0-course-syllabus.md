# Course Syllabus: 3-Day Data Science Prep Intensive

## Target Student
- Entering a US university Data Science program
- May have zero or beginner-level Python experience
- Comfortable with high school math
- Goal: build confidence, learn tools, create first portfolio project

## Course Outcomes

By the end of Day 3, the student will be able to:

1. Write Python scripts to load, clean, and transform data
2. Use Pandas to answer questions from a dataset
3. Create publication-quality charts with Matplotlib and Seaborn
4. Perform basic exploratory data analysis (EDA)
5. Explain core statistical concepts in plain English
6. Build a classification or regression model with scikit-learn
7. Evaluate a model using accuracy, confusion matrix, or error metrics
8. Present findings in a short 3-minute explanation
9. Maintain a GitHub repository with project notebooks
10. Know what to study next in university

## Assessment

No formal exam. Assessment is based on:
- Completed daily exercises
- Final capstone project notebook
- Short oral presentation on Day 3
- GitHub repository with project files

## Materials Needed

- Laptop with internet
- Google account
- GitHub account
- Web browser (Chrome recommended)

## Recommended Datasets

1. **Iris** — classic beginner classification
2. **Titanic** — real-world survival prediction
3. **California Housing** — regression problem
4. **Netflix / Spotify** — interesting for EDA

All available from Kaggle, scikit-learn, or seaborn built-in datasets.

## Recommended Next Steps After Course

| Week | Action |
|------|--------|
| Week 1 | Rebuild all 3 notebooks from memory |
| Week 2 | Complete 2 Kaggle "Getting Started" competitions |
| Week 3 | Learn Git branching; upload 3 projects to GitHub |
| Week 4 | Read one data science case study per day |

## Instructor Notes

- Keep explanations under 10 minutes before returning to code
- Encourage students to guess the answer before showing code
- Celebrate debugging — it is the most important skill
- Avoid perfect accuracy obsession on Day 3; focus on process
- Remind student that university will add the math depth later
